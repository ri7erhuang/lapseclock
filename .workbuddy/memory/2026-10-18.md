## 通读项目 LapseClock（Android 应用）

- 定位：横屏桌面时钟 + 前置摄像头无预览延时摄影，App 内合成 mp4 写入相册 `Movies/Timelapse/`。
- 技术栈：Kotlin 1.9.22 / AGP 8.2.2 / compileSdk 34 / minSdk 31 / Compose BOM 2024.02.00 / CameraX 1.3.1（仅 ImageCapture）/ DataStore / cn.6tail:lunar 1.7.7；视频用 GL + MediaCodec(H.264) + MediaMuxer，零额外依赖。
- 结构：MainActivity（横屏、FLAG_KEEP_SCREEN_ON、权限、onStart 起拍 / onStop 停拍）→ MainViewModel（SettingsRepo + CaptureController + ExportController + WeatherRepo/GoldRepo 状态集中）→ ui（ClockScreen / SettingsSheet / ExportScreen，`Screen` 枚举切换，无 Navigation）。
- 关键机制：
  - 拍照固定时刻表 t0+n×interval，落后即跳拍只统计不补拍（CaptureStatus.skipped）；22:00–08:00 休眠（NightSleep.isSleepHour）屏幕转黑。
  - 默认间隔 60s、分辨率 1600×1200、JPEG 质量固定 100、水印默认开（"LapseClock"+时间，落盘前烧进 JPEG）。
  - 防烧屏：数字区每 120s 随机游走（档位 -1/0/1/2 → x±30/60/80、y±20/40/60 dp）；左上信息组每 120s 水平漂移 10dp 三角波。
  - 合成：ExportController 后台线程 → TimelapseEncoder（decode+EXIF 纠向、GL center-crop、PTS=帧号/fps）→ MediaStore 入库，失败回退 FileProvider。
- 配置：local.properties 提供 qweatherKey / qweatherHost / qweatherCity，经 buildConfigField 注入。
